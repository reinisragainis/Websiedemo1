# Masters Barbershop (GA) — Demo Website Redesign Plan

## 1) Demo Goals
- Present a clean, modern, mobile-first website concept for **Masters Barbershop**.
- Increase booking intent with clear calls-to-action and service transparency.
- Build trust quickly with social proof, barber highlights, and location clarity.
- Keep the demo easy to convert into a production build (Webflow/WordPress/Next.js).

## 2) Target Audience
- Men and teens looking for fades, beard grooming, and consistent barber service.
- Busy professionals who want easy online booking.
- Local customers searching “barber near me” on mobile.
- Parents booking cuts for children.

## 3) Visual Direction

### Brand Style (Demo)
- **Look & feel:** premium, clean, masculine, welcoming.
- **Design language:** bold typography, high-contrast sections, editorial-style photography.
- **Tone:** confident, local, professional.

### Suggested Palette
- **Primary:** #111111 (charcoal black)
- **Secondary:** #C89B3C (barber-gold accent)
- **Neutral BG:** #F7F7F5 (warm light gray)
- **Text:** #222222 / #FFFFFF
- **CTA color:** #0E7A4B (booking green)

### Typography
- **Headings:** Bebas Neue / Oswald (strong, uppercase option)
- **Body:** Inter / Source Sans 3
- **UI text:** Inter medium + semibold for buttons

## 4) Site Architecture (Demo Sitemap)
1. **Home**
2. **Services & Pricing**
3. **Our Barbers**
4. **Gallery**
5. **Reviews**
6. **Contact & Location**
7. **Book Now** (primary conversion page)

## 5) Page-by-Page Wireframe Plan

## Home
**Hero section**
- Full-width image/video of in-shop cutting scene.
- Headline: “Sharp Cuts. Real Craft. Right Here in Georgia.”
- Primary CTA: **Book Appointment**
- Secondary CTA: **View Services**

**Quick trust strip**
- “Top-rated local barbershop”
- “Walk-ins welcome”
- “Open 7 days” (if accurate)

**Featured services cards**
- Haircut
- Skin Fade
- Beard Trim
- Kids Cut
- “See full menu” CTA

**About preview**
- 2–3 sentence shop story + team image

**Reviews preview**
- 3 short testimonials + star rating display

**Map + hours snapshot**
- Embedded map preview + today’s hours + tap-to-call

## Services & Pricing
- Clean category blocks (Haircuts, Beard, Combo, Add-ons).
- Each card: service name, short description, duration, starting price.
- FAQ accordion: walk-ins, late policy, payment methods.
- Sticky mobile CTA: **Book Now**.

## Our Barbers
- Individual profile cards:
  - Photo
  - Name + specialty
  - Experience snippet
  - “Book with [Name]” button
- Optional filter by service specialization.

## Gallery
- Grid of haircut/beard results (before/after optional).
- Lightbox modal for full images.
- Instagram feed integration mock section.

## Reviews
- Pull featured reviews from Google (or mocked demo content).
- Rating summary panel.
- CTA: “Leave us a review” + “Book your visit”.

## Contact & Location
- Address + map embed + parking notes.
- Hours table.
- Phone tap link.
- Contact form (name, phone/email, message).

## Book Now
- Embedded booking widget area (placeholder in demo).
- If no booking software in demo: guided pseudo-flow with time slots.
- Confirmation microcopy + cancellation policy snippet.

## 6) Conversion UX Priorities
- Persistent “Book Now” in sticky header.
- Floating mobile CTA button.
- Service prices visible above the fold.
- Reduce friction: 3-click path from homepage to booking.
- Trust cues near CTA (ratings, years experience, photos).

## 7) SEO & Local Discovery Plan
- On-page local keywords:
  - “Barbershop in [City, GA]”
  - “Fade haircut [City]”
  - “Beard trim [City, GA]”
- Dedicated metadata per page (title + meta descriptions).
- Structured data (LocalBusiness + opening hours + reviews).
- Optimized Google Maps embed and NAP consistency.
- Fast mobile performance and compressed media.

## 8) Accessibility & Performance Requirements
- WCAG-friendly contrast and clear focus states.
- Semantic headings and alt text for all gallery images.
- Lazy-load gallery assets.
- Use WebP/AVIF image formats.
- Target Lighthouse: Performance 90+, Accessibility 90+, SEO 90+.

## 9) Demo Content Checklist
- Shop logo (or temporary concept logo)
- Exterior/interior photos
- 10–20 haircut results
- Service list + prices
- Barber bios + headshots
- Real customer reviews
- Hours, phone, address, social links

## 10) Build Plan (Suggested Sequence)
1. **Discovery mini-brief** (brand preferences + services confirmation)
2. **Low-fidelity wireframes** (homepage + services + booking)
3. **High-fidelity mockup** (desktop + mobile)
4. **Clickable prototype** (Figma)
5. **Demo implementation** (front-end with placeholder CMS data)
6. **Feedback round** and polish

## 11) Stretch Features for a Premium Demo
- Barber availability calendar view.
- “Choose your style” inspiration selector.
- Loyalty banner (“5th cut discount” style promo).
- SMS reminder mock integration.
- Gift card landing section.

## 12) Definition of Done (Demo)
- Fully responsive pages for all core sitemap items.
- Clear brand style consistent across sections.
- Working CTA flow from hero → services → booking.
- Demo-quality copy, images, and interactions.
- Ready to hand off for production implementation.
